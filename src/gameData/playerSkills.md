# Player skills

`skillList.js` defines 20 skills. Each catalog entry has a `name`, an `affects` domain (`batting`, `bowling`, `fielding`, or `personality`), an icon path, and a `frequency` percentage. Career Mode rolls each eligible skill at that percentage, then keeps at most two per player. Bowling and batting skills are limited to the matching player role; fielding and personality skills can be assigned to any role.

National rosters store explicit skill arrays directly on each player record, reflecting known strengths rather than ability ratings. Players without a curated special skill have an empty array in the shared national roster data. The Career Mode profile displays each skill's icon, name, and domain.

Each skill's `impact` contains an `applyTime` value from `skillApplyTimeEnum.js` (`always`, `whenBatting`, `whenBowling`, `powerPlay`, or `last20PercentOfOvers`) and one or more context-specific outcome-delta maps. `batting` and `bowling` apply to the individual skill holder; `fullTeamBatting` and `fullTeamBowling` apply to the whole team. Include only the scopes relevant to that skill. Individual batting impacts apply only to the striker, and individual bowling impacts only to the current bowler. CaptainCalm activates only when its holder is selected as captain. `last20PercentOfOvers` denotes the final 20% of scheduled overs, starting in over 41 for a 50-over ODI. Powerplay timing uses the first 10 ODI overs, first 6 T20 overs, and first 2 T10 overs; micro and mini formats use the first 20% of their scheduled overs, and Test formats have no powerplay. Skill impacts adjust the outcome weights during live delivery resolution. In the Admin Matrix, each outcome row shows the final probability and its net skill impact as the percentage-point difference from the same calculation without skills; the detail panel lists active holders, scopes, timing, and weight deltas.
